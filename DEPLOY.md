# Инструкция по запуску и управлению сайтом

Ваш сайт использует современную архитектуру: **React** (интерфейс) + **JSON** (данные) + **Decap CMS** (админка) + **GitHub** (хранилище).

## 1. Хостинг (Публикация в интернет)

Код уже загружен на ваш GitHub: `https://github.com/IvanTheMorning/Spectran-Site`

Самый простой способ запустить сайт с работающей админкой — использовать **Netlify** (так как Decap CMS создан ими и идеально интегрируется).

### Пошаговая настройка на Netlify:
1.  Зарегистрируйтесь на [netlify.com](https://www.netlify.com) (можно войти через GitHub).
2.  Нажмите **"Add new site"** -> **"Import an existing project"**.
3.  Выберите **GitHub** и дайте доступ к вашему репозиторию `Spectran-Site`.
4.  **Настройки сборки (Build Settings):**
    *   **Base directory:** `spectran-site`
    *   **Build command:** `npm run build`
    *   **Publish directory:** `dist`
5.  Нажмите **"Deploy Site"**.

### Настройка входа в Админку (Identity):
Чтобы вы и менеджер могли заходить в админку (`/admin`), нужно включить сервис Identity:
1.  В панели управления сайтом на Netlify перейдите в **"Site configuration"** -> **"Identity"**.
2.  Нажмите **"Enable Identity"**.
3.  В разделе **"Registration"** выберите **"Invite only"** (чтобы никто посторонний не зарегистрировался).
4.  В разделе **"Services"** -> **"Git Gateway"** нажмите **"Enable Git Gateway"**.

### Создание пользователя (Менеджера):
1.  В вкладке **Identity** нажмите **"Invite users"**.
2.  Введите email менеджера (или свой).
3.  На почту придет ссылка. Перейдите по ней, придумайте пароль.
4.  Теперь вы можете заходить на `ваш-сайт.netlify.app/admin` и входить с этим email/паролем.

---

## 2. Управление контентом (Админка)

1.  Откройте `ваш-сайт.netlify.app/admin`.
2.  Войдите под своим логином.
3.  Вы увидите разделы: **Товары**, **Категории**, **Подкатегории**.
4.  При добавлении/изменении товара и нажатии **"Publish"**:
    *   CMS сама создаст изменения в коде (в JSON файлах).
    *   Отправит их на GitHub.
    *   Netlify увидит изменения и автоматически пересоберет сайт (это занимает 1-2 минуты).

## 3. Локальный запуск (для разработки)

Если вы хотите запустить сайт на своем компьютере:
1.  Установите Node.js.
2.  В терминале в папке проекта выполните:
    ```bash
    cd spectran-site
    npm install
    npm run dev
    ```
3.  Сайт откроется на `http://localhost:5173`.
